# Seguridad de datos

GitHub Pages y la API pública de GitHub no proporcionan autenticación privada dentro de una aplicación estática. La modalidad GitHub de esta versión está diseñada para archivos autorizados para publicación. Los archivos históricos originales permanecen en Google Drive; el repositorio publica únicamente datos consolidados normalizados.

Prioridad de fuentes: 1) detalle operativo autorizado en GitHub; 2) consolidado histórico normalizado; 3) sin información. Nunca se estima ni se arrastra un saldo faltante.
