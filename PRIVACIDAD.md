# Privacidad y tratamiento de datos

- La carga local procesa los archivos en la memoria del navegador.
- La modalidad GitHub descarga únicamente archivos publicados y autorizados en el repositorio configurado.
- Los históricos originales permanecen en Google Drive; GitHub Pages publica el catálogo consolidado normalizado.
- No se almacenan credenciales en la aplicación.
- No deben publicarse reportes reservados en un repositorio público.
- La aplicación no completa datos faltantes mediante estimaciones.
