# Actualización V1.8 · Exportación Enterprise

1. Descomprima el paquete V1.8.
2. Copie todo el contenido interno sobre el repositorio local `comite-cartera`.
3. Acepte reemplazar los archivos existentes.
4. En GitHub Desktop registre el cambio con el resumen: `Agregar exportación Enterprise Dashboard`.
5. Presione **Commit to main** y luego **Push origin**.
6. Espere que GitHub Actions finalice correctamente.
7. Abra la aplicación y actualice con `Ctrl + F5`.

Después de procesar los reportes estarán disponibles cuatro descargas independientes: Excel estándar y Dashboard Enterprise para los escenarios Normal y Proyectado.

El Dashboard Enterprise es un archivo HTML autocontenido. Puede abrirse sin conexión, filtrar por empresa e imprimirse o guardarse como PDF.
