# Actualización V1.7.1 — Corrección del indicador de carga

1. Copie todo el contenido de esta carpeta sobre el repositorio local `comite-cartera`.
2. Acepte reemplazar los archivos existentes.
3. En GitHub Desktop use el resumen: `Corregir indicador de procesamiento infinito`.
4. Presione **Commit to main** y después **Push origin**.
5. Espere la finalización de GitHub Actions.
6. Abra la aplicación y pulse `Ctrl + F5`.

El panel de procesamiento ahora solo aparece durante la ejecución y se oculta automáticamente al concluir o al producirse un error.
