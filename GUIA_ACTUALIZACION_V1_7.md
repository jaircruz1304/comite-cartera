# Actualización a la versión 1.7

## 1. Reemplazar los archivos

1. Descomprime `COMITE_CARTERA_GITHUB_PAGES_V1_7_INTERFAZ_EJECUTIVA.zip`.
2. Copia todo el contenido interno de la carpeta `comite-cartera-github-pages-v1.7` dentro del repositorio local `comite-cartera`.
3. Acepta reemplazar los archivos existentes.
4. Confirma que existan:
   - `assets/COMITE_BASE.xlsx`
   - `assets/logo_CTH.png`
   - `index.html`
   - `js/app.js`
   - `assets/styles.css`

## 2. Publicar

En GitHub Desktop escribe como resumen:

`Reorganizar interfaz ejecutiva e integrar identidad CTH`

Después:

1. Presiona **Commit to main**.
2. Presiona **Push origin**.
3. Espera que la acción de GitHub Pages termine con marca verde.
4. Abre la aplicación y presiona `Ctrl + F5`.

## 3. Verificación visual

La pantalla debe mostrar, en este orden:

1. Parametrización.
2. Carga de archivos.
3. Procesamiento.
4. Descargas.
5. Dashboard de resultados.

En el encabezado debe aparecer el logo CTH y la leyenda **Desarrolladora: Lizbeth Sanipatín**.
